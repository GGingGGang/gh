# D 작업 안내

D는 EU AI Act의 **협상 국면**을 퍼트남의 양면 게임으로 분석한다. [A의 서론](../A/01_AI_Act_핵심과_입법_필요성.md)에서 입법 목적과 쟁점을 받아, [B의 외부 이해관계자 분석](../B/01_외부_이해관계자.md)과 [C의 내부 이해관계자 분석](../C/C_역할과_내부이해관계자.md)을 연결한다.

- [AI Act 협상 국면과 양면 게임](01_AI_Act_협상국면과_양면게임.md): 국면별 Level I·Level II, 쟁점별 타협, 발표용 결론.
- [추가 검증을 반영한 종합 결론](02_종합결론.md): 반복적 위임 조정, 이해관계의 다양성, 프독이의 연합 자원, 실제 승인과 남은 이견을 연결한 최종 설명과 발표문.

결론에는 [A의 입법 흐름 검증](../A/03_입법_흐름과_검증.md), [B의 보강사항](../B/06_검증결과와_보강사항.md) 및 [요구·타협 대조](../B/07_최초요구와_타협_검증표.md), [C의 입법 흐름 검증](../C/입법흐름_검증보고서.md)을 반영했다. 기존 국면 분석도 같은 기준으로 수정했다.

**분석 범위:** 2023년 하반기 범용 AI·기반모델 규제 협상과 2024년 승인·채택. 2021년 제안과 2024년 공포법은 각각 출발점과 결과를 확인하는 자료로 사용한다.

**용어:** B가 정리한 기업·단체는 공식 Level I 협상대표가 아니다. 이들의 공개 요구는 기관 간 협상에 투입된 선호와 압력을 보여준다. C가 정리한 이해관계자 중에서도 회원국·의회처럼 공식 승인권을 가진 행위자와 기업·단체처럼 영향은 행사하지만 법적 승인권은 없는 행위자를 구분한다.
