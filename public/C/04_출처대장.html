04. 검증자료와 출처 대장

확인 기준일: 2026-11-16. D·C·N 번호는 분석 문서와 원문을 연결하는 자료 식별자다. 자료별 확인 위치·방식과 접근 범위는 아래에 구분했다. D17 24쪽과 N02 2쪽은 원문 페이지 이미지도 대조했다.

자료의 존재와 당사자의 영향력을 구별한다. D14는 당시 제한적으로 제출한 뒤 공개된 자료이고, D08·D17은 같은 위원회 사건에 관한 요약·속기록이다. 5요소 분석은 이러한 출처 성격을 반영한다.

정부·의회 공식 자료도 기능이 다르다. 표결표는 승인 행동, 속기록은 실제 발언, 정부 성명은 해당 정부의 설명·평가, 당사자 공개서한은 요구를 입증한다. 어느 자료도 그 자체로 다른 행위자의 내심이나 비공개 협상의 전모를 입증하지 않는다.

작성 주체·공개 방식·독립성

자료 묶음 작성 주체·관찰 대상 당시 공개 방식 독립성·해석 범위
D14 의견서·이메일 기업의 입장과 정부 전달·내부 전달 흔적 제한 전달 후 정보공개로 공개. 당시 대외 공개 행동으로 분류하지 않음 한 제출 사건의 문서와 이메일. 정부 입장 채택의 독립 증거가 아님
D08·D17 독일 의회의 같은 2023.12.13 회의 요약·속기록 공개 회의 기록·공식 요약 같은 사건의 재서술. 정부 성공 주장과 야당 반론은 상반된 평가의 존재를 입증할 뿐 어느 평가가 맞는지 판별하지 않음
D06·D07·D20 장관 공동성명·공동 제안·승인 설명 D06 공개 성명, D07 언론 공개 사본으로 최초 공개 경위 미확인, D20 정부 발표 전재 서로 다른 시점의 정부 입장 자료. 전재본을 원 보도자료와 별개의 증거로 세지 않으며 정부의 성과 설명은 외부 평가가 아님
D10·D11·D19 중소기업 단체·시민사회·권리자 등의 직접 요구 공개 입장문·공개서한 해당 서명자·단체의 요구. 전체 산업계·시민·노동자의 선호 조사로 일반화하지 않음
C02 의장국이 COREPER에 제출한 타협 분석 공식 문서의 현재 열람 가능성 확인 절차·문안 비교에는 유용하나 의장국의 설명 위치를 고려. 국내 원인의 독립적 평가가 아님
D21·N01 인터뷰 직접 발언 / 프랑스 정부의 자문위원 명단 언론 인터뷰 / 정부 공개 게시물 각각 선호와 접근 경로를 보여줌. 명단은 기업 요구의 채택을 입증하지 않음
D12·N02 회원국 성명 / 실제 이사회 표결 공식 회의 문서 서로 다른 관찰 대상. ‘우려가 남았다’와 ‘찬성했다’를 함께 확인하되 찬성 이유는 별도 조사
N03·N04 의회의 각기 다른 승인 단계에 대한 공식 발표 공개 발표, 현재 원문 직접 접근 제약 공식 검색 본문 확인. 전체 표결표·호명 투표 원문은 미확보

연구의 사례 선택은 직접 요구와 전달 경로를 확인할 수 있는 자료의 존재에 기반한다. 영향력이 가장 큰 행위자를 포괄적으로 선별했다는 뜻은 아니다. 이에 맞춰 현재 결론은 독일에서 관찰된 경로와 이사회 절차 중심으로 제한했다. 문서 수·인용 수·그래프 중심성을 정치적 영향력으로 사용하지 않는다.

검증의 한계

프랑스의 자문 참여 경로와 이사회 실제 승인표를 확인했다. 이탈리아 국내 부처·기업 간 조율, 의회 정치그룹별 협상 과정, 기업의 문구 제안이 채택된 수정 이력은 확보하지 못했다. 이 공백은 보고서에서 미확인으로 남겼다.
