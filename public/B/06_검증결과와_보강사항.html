B 자료 재검증 결과

확인·수정: B / 2026-11-16

종합 판단: 핵심 설명은 유지하되, 그래프 해석과 순차적 양면게임 설명을 수정했다. 외부 요구의 다양성과 정부·EU 협상의 연결은 1차 자료로 확인된다. 다만 이를 곧 기업의 정책 지배나 프독이의 전면 승리로 해석할 수 없다.

무엇을 확인하고 바꿨는가

검토 항목 판정 반영 내용·근거
Graphify가 입법 흐름을 보여준다는 설명 표현 수정 graph.json은 directed: false. 관계망을 날짜에 따라 재구성한 분석과 원래 그래프를 구별. EXTRACTED도 인과 인증이 아님. 05번
외부 요구 → 협상 → 승인이라는 일방향 모형 이론 수정 Putnam 원문 436쪽은 사전 협의·예상 거부·반복을 명시. 순서는 증거 배열용으로 한정. 02번
외부 행위자는 모두 정부의 국내 지지층이라는 처리 구분 보강 국내 정부 접촉과 EU 기관 직접 접근을 분리. ‘외부’는 공식 협상 대표 밖을 의미. 01번
프독이의 힘 제도적 근거 추가 2023년 공식 표결 인구 합계 약 47.07%. 세 나라만으로는 저지 불가, 네 번째 동참국이 있으면 저지 연합 구성 가능. 실제 동참·위협 효과는 미확인. 03번
산업계의 동일한 선호 반대 사례 보강 ERT는 모델 규제 강화에 반대하면서 정보 제공 의무는 요구. DIGITAL SME와도 구별. S22
합의 이전 권리자 요구 새 1차 자료 추가 EWC의 2023-11-14 서한. 2024년 독일 서한을 소급하는 대신 당시 자료 사용. S21
연구기관의 설계 개입 누락 행위자 추가 Ada Lovelace Institute의 개발자 책임·추가 의무 검토. S28
승인 촉구 서한으로 실제 승인 설명 증거 보강 독일 2월 승인 설명과 프랑스 최종 채택 성명 추가. 요구와 행동을 분리. S25 · S26
초기 의회안과 최종 차등 구조 비교 기준 명료화 2023년 6월 제28b조와 연말의 시스템 위험 접근을 구별. 이사회 10^26 → 타협 10^25의 구체적 절충 추가. 07번
갑작스러운 독일 입장 전환 확정 유보 정부는 9월 입장과 연속성을 주장. 의원 질문과 정부 답변을 분리. 9월 원문 대조가 더 필요. S27
기업 로비가 최종 문구를 결정했다는 인과 여전히 미입증 이메일·접촉·유사한 선호는 확인. 문구 변경 이력과 내부 판단 기록은 부족. 02번

같은 자료로 가능한 다른 설명

양면게임은 자료를 정리하는 데 유용하지만, 다른 설명을 지운 채 유일한 원인으로 제시해서는 안 된다.

설명 가설 현재 지지하는 자료 더 확인해야 할 증거
국내 기업 요구가 정부의 수용 범위를 제한했다 Aleph Alpha 전달 이메일·정부 접촉, 선호의 유사성 요구 전후의 내부 입장 변화, 반영된 문구, 의사결정자의 구체적 설명
정부가 자체 산업정책 목표로 공동 대응했다 장관 공동성명의 경쟁력·혁신 목표 기업 요구와 정부의 독자적 판단을 분리할 내부 조정 기록
의회와 이사회의 제도적 교섭이 최종 설계를 만들었다 수정 위임, 양 기관 요구 사이의 연산량 기준, 최종 차등 의무 쟁점별 협상안 변경 이력과 상대 기관의 반응

이 세 설명은 서로 배타적이지 않다. 현재 증거는 ‘기업 요구만으로 결정됐다’는 단일 원인 설명보다, 국내 요구·정부 목표·기관 간 교섭을 함께 검토하는 설명을 뒷받침한다. S01 · S05 · S15

발표에 바로 쓸 수정 결론

저는 외부 이해관계자와 양면게임 분석을 맡은 B입니다. AI Act에서는 모델 개발사, 후속 기업, 창작자, 시민사회가 서로 다른 부담 배분을 요구했습니다. 프랑스·독일·이탈리아는 공동 대안과 이사회 위임 경로를 갖고 있었고, 당시 표결 인구의 약 47%를 차지해 다른 국가를 끌어들일 경우 강한 저지 연합을 만들 수 있었습니다. 그러나 세 나라만의 법적 거부권은 없었고, 반대했던 차등 의무도 최종 법에 남았습니다. 따라서 이 협상은 프독이의 일방적 승리보다, 내부 요구와 상대 기관의 수용 가능성을 함께 고려한 절충으로 설명하는 것이 타당합니다.

이 발표문은 검증한 사실을 연결한 B의 해석이다. 퍼트남 이론의 인과 검증을 완료했다거나 기업별 영향력을 계량했다는 의미는 아니다.

남은 공백과 파일 범위

  • 국가 간 증거 비대칭: 독일의 전달·접촉 기록은 비교적 탄탄하지만 이탈리아의 국내 조율은 여전히 부족하다. 세 나라에 같은 메커니즘을 자동 적용하지 않는다.
  • 미국 기업: OpenAI 백서 공개본은 이번에도 접근 거부. OpenAI·Google·Microsoft·Meta의 개별 요구를 한 진영으로 묶어 확정하지 않는다.
  • 윈셋: 최초 요구와 수용선은 다르다. 최종 승인이 최초 요구와 달랐다는 사실만으로 윈셋의 확대나 축소를 판정할 수 없다.
  • 자료 범위: B 문서와 핵심 근거, 관련 그래프 연결을 검증했다. 작업공간 전체 파일의 전수 검증은 아니다. 기존 A·C·발표 자료 및 Graphify 원본은 수정하지 않았다.
