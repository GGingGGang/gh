## 범위와 용어

- **중심 시기:** 2023년 하반기 기반모델·범용 AI(GPAI) 협상. 2024년 승인 국면은 구별한다.
- **주된 분석 단위:** 의장국의 기관 간 교섭과 이사회 내부 위임·승인. 각국의 국내 입장 형성은 하위 과정이다.
- **외부 이해관계자:** 공식 입법협상 대표 밖의 기업·단체·연구기관. EU 바깥의 행위자만을 뜻하지 않는다.
- **프독이:** 프랑스·독일·이탈리아.
- **모델 용어:** 당시 foundation models와 공포법의 GPAI 모델을 완전히 같은 정의로 취급하지 않는다.

## 핵심 판단

서로 다른 공개 요구, 기업의 정부 전달과 정부 공동문서의 의장국 전달, 위임 수정과 기관 간 타협은 각각 확인된다. 특정 외부 요구가 정부의 수용선을 바꾸고 최종 문구를 만들었다는 연결은 미확인이다.

프독이의 공동 제안과 2023년 표결 인구 약 47.07%는 협상 자원이다. 세 나라만의 저지권은 없었으며 실제 저지 위협 때문에 상대가 양보했는지는 확인되지 않았다.

공개 요구와 최저 수용선, 접촉과 정책 영향, 잠재적 자원과 실제 효과를 구분한다. 주장마다 확인·가설·미확인·해당 없음을 표시하며, 자료 수를 인과 증거의 강도로 바꾸지 않는다.
